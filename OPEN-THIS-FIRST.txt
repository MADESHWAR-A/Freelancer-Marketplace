WORKLY REVIEW READY - QUICK START

1. Open this folder in VS Code.
2. Open Terminal.
3. Run:
   npm install
   npm start

4. Open:
   http://localhost:3000

IMPORTANT:
Do NOT use VS Code Live Server for the normal demo. Express serves the frontend and API together.

If you DO use Live Server:
- Start npm start first.
- Open auth.html with Live Server (usually http://127.0.0.1:5500/auth.html).
- The updated frontend automatically sends API requests to http://localhost:3000 and WebSocket chat to port 3000.
- Keep npm start running.
